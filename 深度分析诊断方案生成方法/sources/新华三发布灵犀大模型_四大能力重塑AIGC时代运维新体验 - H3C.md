# 新华三发布灵犀大模型，四大能力重塑AIGC时代运维新体验

【发布时间：2024-04-18】

近日，紫光股份旗下新华三集团在以“×AI”（乘AI）为主题的2024媒体与分析师沟通会上，重磅发布灵犀大模型，实现AI技术与传统运维的深度融合创新，在智算热潮中，为统一运维提供更高效智能的动力引擎。灵犀大模型是新华三将AIGC引入智能运维场景的全新探索成果，将帮助客户实现运维效率和体验的全面重塑。

![](https://resource.h3c.com/cn/202405/28/20240528_11317495_image001_2155001_30008_0.jpg)

当前AI算力已成为刚需，大模型的快速进化促进了生产力效率提升，智能运维正站在挑战与机遇的十字路口。面对数据量爆炸式增长和技术的快速迭代，智能运维所面临的信息处理任务愈发复杂，对算法和模型的精确度、效率要求也越来越高；与此同时，智能运维的边界在不断扩展，需要覆盖更多场景，满足更多个性化需求。

新华三集团全新发布的“灵犀大模型”可通过灵犀助手入口，提供包括知识问答、配置指导、智能运维、产品推荐等在内的“规-建-维-优”一站式服务，依托AI可视、AI排障、AI调优和AI安全四大能力，为百行百业打造智能运维“新大脑”，提高ICT统一运维的效率和效果。

![](https://resource.h3c.com/cn/202405/28/20240528_11317496_image002_2155001_30008_0.png)

**AI****可视****业务管理更清晰**

数据可视化在运维管理中扮演着至关重要的角色。灵犀大模型具备智能流量监控、终端体验可视、多维数据分析、全时信息可视能力，应用AI技术实现网络设备与平台协同计算，对设备日志、流量模型、应用等多维信息进行AI分析，完成贯穿应用和网络基础设施的信息洞察。

智能流量监控：对RoCEv2会话进行智能流量监控和多维数据采集分析，实时掌控业务状态。

终端体验可视：基于AI对无线终端进行应用体验分析，实现对通信效果的准确评估，体验判断准确度可达92%，为实现网络自进化奠定基础。

多维数据分析：通过多维数据的采集及多种算法的整合，实现端到端的健康度可视。

全时信息可视：对全网实现基于时序的可视化和动态预测，让用户及时掌握全网信息。

**AI****排障****系统运行更高效**

在大规模基础设施运维工作中，排查故障通常需要耗费大量的时间和精力。基于海量日志及运维数据训练结果，灵犀大模型可以实现链路级、设备级、网络级到应用级快速排障，覆盖90%以上的网络问题类型，大大减轻传统运维负担，确保算力的连续性和稳定性。

**网络智能诊断：**基于知识图谱构建网络智诊和终端智诊功能，让AI能够“理解”网络。

**多算法交叉排障：**采用图计算、随机森林、RNN、文本相似性分析等多类算法进行交叉排障验证，快速定位排障。

**AI****调优****性能提升更智能**

智算场景非常依赖稳定的数据传输，精确的网络资源调度对于完成全场景网络智能调优、提升链路效能至关重要，这也对运维技术提出全新挑战。灵犀大模型可以持续学习网络状态，基于用户业务提供最优配置建议和动态调优能力，实现自适应和自进化的网络调优。

**智算性能优化：**利用AI算法和数据模型提升网络带宽，实现智算网络的流量自适应和动态负载均衡，提升系统性能。

**无线射频调优：**利用专项训练模型实现基于用网情况预测的智能无线射频调优。

**应用实时保障：**通过应用识别和智能分析，实现应用管控、差异化保障、应用自动调优及风险阻断。

**AI****安全****运维保障更智慧**

网络安全是企业安全保障的基石。灵犀大模型将AI技术应用于业务的全生命周期，通过网络及安全设备策略联动，实现动态学习用户及应用网络行为，有效提升安全效率和效果。

**建立行业模型：**打造行业专属模型，聚焦预训练、模型微调、评估测试三大核心内容，实现数据安全治理。

**内容合规防护：**从输入侧、模型侧、输出侧三个层面对违规信息进行过滤和规避，全面保障内容合规。

**保障运行环境：**聚焦区域边界防护、公共安全服务、流量安全监测、算力设施监管四大核心场景，打造智算安全底座。

新华三集团拥有包括完整的云网安算存端产品体系在内的端到端智算能力，以及21年行业网络建设经验和产品研发经验，积累了大量运维案例和专业语料，可以全面满足灵犀大模型训练需求，持续为智能运维注入具有洞察力的专家经验。与此同时，新华三也将“AI in ALL”战略落地到灵犀大模型，结合独有的NAI智原生技术，提供设备侧AI功能，形成云端协同的全栈AI能力布局。

大语言模型在运维领域有着广阔的应用空间，未来新华三集团将持续深耕AIGC引入智能运维场景的新思路和新方案，乘AI之风，充分发挥“算力×联接”的倍增效应，为百行百业打造更懂行业运维需求的大模型，加速AIGC时代运维高质量发展。
