# “一人公司”，为何在大湾区遍地开花？

    推开门，没有前台，看不到工牌，只有一两个工位、几台电脑……这里是深圳南山区“模力营”，在这个1万平方米的创业社区里，生长着近200家“一人公司”（One Person Company，简称“OPC”）。腾讯前AI视觉设计师陈顺洋即将入驻这里，他的AI穿衣试衣产品，刚拿下中东和泰国的大单。

    “一人公司”是指个人借助AI工具，独立完成产品设计研发到市场投放的全链路商业闭环，实现“单人成军”的创业方式。

    随着人工智能技术的快速发展，“一人公司”今年迎来爆发式增长，在大湾区遍地开花。

    各级政策也纷至沓来：广东出台支持人工智能OPC创新发展行动方案，这是全国首个省级OPC专项政策，到2028年建成百个社区、培育千家标杆企业；深圳发布人工智能OPC创业生态行动计划，到2027年底集聚超万名人工智能创新创业人才……

    算力、场景、空间被打包送到创业者面前——大湾区正在把“投资于人”落实到最小创业单元。这股随AI吹起的创业风，对创业者来说意味着什么？记者走进大湾区多个OPC社区，与创业者、观察者、法律专家深谈，还原“一人公司”的真实模样。

    采写：南方日报记者 崔璨

    统筹：何雪峰

    AI时代的小微企业

    “一人公司”并非凭空出现。

    2026年年初，随着人工智能代理（AI Agent）从“辅助工具”向“执行主体”加速演进，一种以“单人+AI系统”为基本生产单元的创业形态，开始进入更具商业化想象空间的产业场景。

    首先，“一人公司”不一定只有“一个人”，而是“尽可能少的人”。

    国研新经济研究院创始院长、智能经济首席专家朱克力认为，AI技术的成熟，使得过去必须由多个专业岗位协作完成的“研发—生产—营销—服务”全链路，可以被熟练驾驭AI工具的个体所贯通，AI扮演了“第二大脑”与“可扩展执行层”的角色，创新的最小经济可行单元正在从“组织”下沉至“个体”。

    深圳市合智创新人工智能科技有限公司创始人黄佳伟，有过3次创业经历。前两次是传统模式，主要从事校园文创、新媒体运营及教培相关业务。这一次，他借助AI智能体，切入教育科技赛道。

    “以往创业，要找场地、招人、投研发，相对重资产。”黄佳伟回顾前两段创业经历时总结道。那时，一个十几人的团队完成一套文创产品，从需求对接到生产交付，需要两三个月。

    到2024年，当他启动以AI教育为核心的第三次创业时，规则开始变了。“现在，我相当于带着一堆‘智能体员工’工作。每个智能体代表一个员工，而且不需要长时间培养。”黄佳伟将AI智能体定位为“队友、创业导师和市场调研员”。

    当创业者能熟练使用AI智能体后，“一人公司”最显著的优势——低成本与高效率得以显现。

    “以前光写一份靠谱的商业计划书，就需要一个团队分工协作，耗时数月。现在，我只要把问题抛给AI，让它扮演市场专家、产品经理、投资人等不同角色，一天就能迭代十几版，连带着数据图表和PPT都可以自动生成。”大公坊iMakerbase创始人丁春发认为，从研发、供应链、推广到销售全链路，AI工具都已经可以部分替代人力。

    其次，“一人公司”也是“公司”，它与个体工商户有本质区别。

    据深圳市市场监管局的相关解释，“一人公司”具有独立法人资格，股东以认缴出资额为限承担有限责任；个体工商户不具备法人资格，经营者需以个人或家庭全部财产承担无限责任。

    综合开发研究院（中国·深圳）企业与市场研究中心执行主任、博士郑天骋向记者解释，如果把创业模式画成一条光谱：最左端是个体户——单人经营、无限责任、无需AI加持；中间是传统小微企业——多人协作、科层管理、局部使用AI工具；最右端才是AI时代的“一人公司”——一两人核心团队加AI智能体军团，完成传统数十人的业务闭环。

    深圳市人工智能行业协会执行会长郎丽艳还观察到，这股由AI驱动的“一人公司”浪潮呈现出了鲜明的“硬科技”属性——“一人公司”能迅速将大模型的算法能力转化为解决具体问题的智能体或解决方案，成为驱动经济社会智能化升级的有生力量。

    创业者多有丰富经验

    对“一人公司”创业者而言，新项目的起点大多是发现了新需求。

    陈顺洋是连续创业者，他发现传统电商服装退货率高达70%，于是利用AI编程，做了一款AI穿衣试衣推荐产品——集成在智能魔镜里，拍照就能量体，输入需求就能得到穿搭推荐。

    随后，他成立了爱穿搭科技后，用时一周实现产品化，两周后签约首个客户。“传统的公司可能要开发、产品经理、设计、测试、交付、运维……我们有AI的加持，能把个人能力放得很大。”

    还有为数不少的创业者从其他领域跨界而来，带着深厚的积累转投AI。

    何鸿恺在美国做了10年风险投资，管理过上亿美元基金，去年却回国在广州创办了一家仅3人的公司。他开发了一款AI拍照应用，可以翻译菜单、标注过敏原，从创意到上线只用了两天。“以前没人愿意做这种‘太小’的生意，但有了AI，开发成本很低。花两天试试，不行就换一个。”他计划每年推出10到20款这样的AI应用，全部面向海外。

    创办AI医疗公司的萧晨熙有医学背景，但编程零基础，于是利用十几个AI智能体组建起“技术团队”。AI带给他的不仅是技术补足，更是重心的转移：“以前每天复盘问题、解决问题，现在更多时间花在学习和寻找新机会上。”

    曜境文化的司庆正在探索AI动漫微短剧，一名创作者加上AI工具，3天可完成2D短片，4天可完成3D短片。传统模式下这需要一个完整的内容团队。

    数据也能证实“一人公司”的狂飙突进。

    中关村人才协会发布的《中国OPC发展趋势报告（2025—2030年）》显示，截至2025年6月，全国一人有限责任公司突破1600万家，2025年上半年全国新注册OPC数量达到286万户，同比激增47%，占全部新注册企业的23.8%。

    据不完全统计，全国已有20多个城市出台OPC专项扶持政策。在深圳，首批10个OPC社区已正式亮相，合计建筑面积超32万平方米，覆盖9个区。

    OPC社区有什么作用

    对于“一人公司”的能力边界，许多创业者有着清醒的认知。

    黄佳伟告诉记者，最适合“一人公司”的领域主要集中在“软”的方面，比如，做自媒体、开发解决特定场景需求的小软件、打造线上课程、提供法律或设计咨询等。利用AI，一人可以完成内容策划、制作、分发乃至客服的完整流程。

    “但更‘硬’、更‘重’的领域，比如人形机器人，那是不可能的。”黄佳伟划出了界限。

    “一人公司”的优势阶段也集中在“从0到1”的验证期。

    黄佳伟自身的经历即是例证：通过AI与教育科技的深度融合，他一人贯穿了从创意提出、市场调研、产品设计到初步运营的全链条，成功实现了“从0到1”的突破。解决了创业最关键的“可行性证明”难题。

    一旦业务进入“从1到10”的规模化阶段，需要更稳定工程化的产品、更大规模的市场交付时，引入真人专业团队就成为必然。

    明源不动产研究院副院长黄乐总结道：“OPC模式的核心是一人主导加AI智能体，一个人可完成传统团队的工作闭环。但瘦身的前提是，你得先有骨架——产品判断、客户信任、商业闭环、风险承担，这些事AI一件都替不了。”

    事实上，“一人公司”也并非要单打独斗。在实际运营中，公司以一名核心创业者为主导，依托AI智能体、少量辅助人员和外包协作，就能高效运转。

    龙岗OPC社区运营者邱秋告诉记者，当前最受创业者欢迎的共享服务前三位是算力补贴、法务咨询和财税代办——这些原本需要创业者自己跑腿的事务，可由社区统一对接第三方机构解决。

    风口上有机遇也有考验

    “一人公司”站上风口的同时，风险也在浮出水面。

    以北京中关村某OPC社区为例，有人3个月“烧”光10万元启动资金，最惨的一个月只接到两个小订单，连房租都不够付，今年2月注销了公司。

    美国远程医疗公司Medvi曾靠两名员工与10余种AI工具，一度创下年入4亿美元的商业奇迹，并预计2026年实现18亿美元营收。然而进入2026年，Medvi接连陷入虚假宣传、违规营销、法律诉讼和FDA警告等多重争议。

    对此，中央财经大学中国互联网经济研究院副院长欧阳日辉提醒，虽然“一人公司”很灵活，但要发展壮大，面临着天然的瓶颈：资金、精力、能力，以及抗风险能力。

    “一个人”并不意味着轻松，许多创业者对此深有体会。

    “自己要做开发、做产品、做运营、做商业拓展，精力根本不够分。”陈顺洋坦言，工作非常饱和，虽然有AI加持，但决策、担责、扛风险全是创业者自己的。他还算了一笔账：自己充了1000美元到国外接口，本以为够跑一个月，结果三天就烧完了。“AI为了完成指令，会不断自我调整、自我对话，消耗的算力比预想大得多。”

    陈顺洋的遭遇并非个案。国金证券的研究报告指出，几十上百个AI Agent在后台并行调度与高频交互，会产生极为庞大的数据吞吐量，驱动推理Token消耗量呈指数级扩张。“一人公司”的账本正在从“人换时间”转向“算力换人力”，算力成本可能占到总成本的八成以上。

    “一人公司”创业，对个人精力也有着极高的考验。

    在深圳龙岗“模力谷”做AI视频的黄忠忠是典型例子。他用AI视频技术为央视制作宣传片，累计播放量超3.8亿。但成绩的背后，他的公司只有多个OPC小组，没有多级管理，只能每天从早忙到晚，一刻不得歇。

    “‘一人公司’需要创业者有更全面的能力，还有更强的自律能力。”黄忠忠坦言。

    合规风险不容忽视

    除了成本、精力，对许多“一人公司”创业者来说，法律合规是最容易被忽视的问题之一。

    欧阳日辉指出，“一人公司”与个体工商户的核心区别在于责任承担方式——只要公司合法经营、财产严格分离，即便赔光注册资本，也不会牵连个人及家庭财产。但这层“保护服”有一个关键前提：财产必须严格分离。

    根据《公司法》规定，“一人公司”股东需自行证明公司财产独立于个人财产，若无法证明，则需对公司债务承担连带责任。这意味着，如果创业者的个人账户与公司账户混用，一旦公司出现债务纠纷，个人房产、存款都可能被强制执行。

    在司法实践中，“一人公司”因股东单一、缺乏内部监督制衡机制，已成为法人人格否认制度适用的“重灾区”。股东不仅要面对传统公司的经营风险，还要额外面对“自证清白”的法律负担——需要建立独立的财务管理制度和审计制度，保留完整的会计账簿和交易记录。

    除了传统的财产混同风险，“一人公司”还面临新型法律挑战。

    珠海市司法局在法治宣讲中指出了三类核心风险：主体责任认定、知识产权归属、数据安全合规。国家互联网应急中心和国家工信部近期对OpenClaw等AI工具发布了官方安全预警，提示创业者警惕提示词注入、插件投毒、数据泄露等新型风险。

    对此，多位业内人士也发出呼吁，加紧完善创业“基础设施”——让法律合规框架、财税支持、资源中台等变得标准化、平台化且易于获取。

    “一人公司”只是起点

    在这股“一人公司”热潮吹动下，我们该如何冷静看待？

    郎丽艳指出，各级政策支持“一人公司”的目的不是鼓励人人都去创业，而是为那些有创意、有能力、有意愿的人扫清障碍。“‘一人公司’是多元就业形态中的一种补充，而不是替代。”

    对于那些真正跑通的人来说，“一人公司”只是起点，他们终将经历从“一个人”到“一支队伍”的蝶变。

    面对“是否需要高深技术背景”的疑问，很多受访者的回答有着相似的逻辑：“技术门槛不高，更多是自学能力、自控能力和判断力。”

    黄佳伟强调，“一人公司”创新者要具备的核心技能是洞察力与执行力——发现真实市场痛点的能力；抛开畏难情绪，立即动手与AI对话、将想法落地的勇气。

    黄忠忠给想入局者的建议异曲同工：“要有非常强的自驱力和自学能力。”在他看来，AI是放大器，但放大器前面得有东西可放。

    “一人公司”的兴起，改变的不仅仅是创业的门槛，更是看待工作、组织与价值创造的方式——在AI时代，个体可以前所未有的强大，但同样需要生态的滋养、法律的保障和理性的敬畏。

    这场浪潮将走向何方？郑天骋认为，OPC的兴起催生了新的商业模式，就像毛细血管一样嵌入产业链，提升整个产业发展的韧性与活力，也让城市竞争从给地给钱的“硬比拼”，升级为算力、场景、生态的“软较量”。“谁能吸引个人创业者，谁就能把人口数量转化为创新密度。”

    黄乐进一步指出，培育“一人公司”，写字楼和园区也需要转变观念，从原来的“招商”变成“育商”，从“捡成熟桃子”转向“种树育苗”。

    未来的大湾区，将是一片“创新雨林”——既有参天大树般的大企业，也有灌木、花草般的“一人公司”，它们各自生长，又相互滋养。这片雨林向每一颗种子敞开怀抱：你无需千军万马，需带着创意与决心。但出发之前，请先看清脚下的路——不是每一株草都能长成树，也不是每个人都适合做“特种兵”。

    延伸

    如何为创业者托底？

    面对“一人公司”发展遇到的各种现实问题，大湾区各地政府正在用“真金白银”和贴心服务为创业者托底。

    记者根据受访创业者的反馈统计发现，“一人公司”发展迫切需求排在前三位的是：算力成本、获客渠道、现金流管理。

    在算力方面，广东省级方案完善了“算力券”制度，降低OPC实际算力支出成本，搭建智能算力公共算力服务平台。

    从制度保障层面，广州发布《优化营商环境措施三十条》，首次将优化营商环境工作方案以市委深改委“一号文”印发。其中最引人关注的是，广州首次明确提出培育“人工智能+超级个体”，向创业者推送训力/算力、模型/语料、场景落地、启动资金、安居补贴等政策大礼包，并选取部分国企园区向OPC企业提供梯度化、场景化的Token优惠服务。

    在获客和场景方面，深圳提出政务场景项目最高补贴500万元，为OPC企业开放应用场景；惠州仲恺设立了全市首个OPC专属服务窗口，将工商登记、银行开户、社保开户整合为“一件事”，力争一日办结。

    在空间和安居方面，佛山推出了“三免”政策，提供最长3年的场地、水电、设备费用减免；安居保障涵盖7天免费住宿、每月750元租房补贴、免租人才住房以及最高1000万元购房补贴——从一张床到一套房，创业的事有人管，生活的事也有人管。

    今年以来，广东、湖北、江苏等地还密集出台扶持政策，以“政府引导+市场工具”组合拳，为OPC发展搭建全周期金融支持体系。

    苏商银行特约研究员武泽伟认为：“金融助力OPC发展，标志着金融服务模式正主动适配新质生产力的微观载体。这不仅是顺应AI时代‘一人公司’创业浪潮的前瞻性布局，更通过‘政府引导+市场工具’的组合拳，精准破解了其轻资产、无抵押、高成长的融资难题。”
