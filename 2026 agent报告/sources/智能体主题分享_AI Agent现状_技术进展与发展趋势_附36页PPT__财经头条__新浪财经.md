**全文约1.3万字，阅读时间20分钟**

**文/王吉伟**

可能大家都没想到，前两天还被媒体大谈特谈正在进行“大模型阻击战”的OpenAI与谷歌，转身就与他们的竞争对手共同成立了Agentic AI基金会（Agentic AI Foundation，AAIF）。

12月10日，OpenAI与Anthropic和Block在Linux基金会旗下共同创立了AAIF，旨在推动Agentic AI系统的开源开发与标准化。目前成员包括亚马逊云科技AWS、彭博社、Cloudflare、谷歌、微软等一批科技巨头。

该基金会已启动三大基本项目：Anthropic的模型上下文协议（Model Context Protocol，MCP）（连接AI模型与工具、数据的标准，已被超10,000台服务器采用）、Block的Goose框架（构建智能体工作流的开源框架）以及OpenAI的AGENTS.md（为AI编码Agent提供项目指导的标准化格式，已被超60,000个开源项目采用）。

![](//k.sinaimg.cn/n/sinakd20111/179/w640h339/20251219/7d15-d65b8e821e59cd44a238bcb7d07a1679.png/w700d1q75cms.jpg)

影响自然是积极的。这三大标准的统一与快速推广，会结束之前Agentic AI各自为政的阶段，极大加快Agent技术的标准化、可编排性、可重复性、可互操作性。它在大幅降低企业引入Agentic AI的门槛，可能也会加速企业级Agent平台的横向竞争。

企业之间原来的多维度竞争，以后可能会更倾向于构建基于MCP的工具体系、使用Goose作为调度器以及用AGENTS.md规范项目结构。这可以算是Agentic AI行业的大事件，标志着Agentic AI将会从原型时代迈向产业时代。

它还会将AI平台从模型中心带向了Agent中心，企业技术栈也将从API调用模型转向工作流驱动的Agentic AI平台，技术范式发生了根本性变化。这也让大模型优势变得不那么重要，毕竟模型领先不等于Agent生态领先。

简单来讲，AAIF的成立，相当于OpenAI、Anthropic等大模型厂商获得了行业规则制定权，就连巨头们也选择共同制定规则，而不再去打架制定各自的闭源标准。那么全球厂商要搞Agentic AI，就不得不去拥抱这个全球市场准入标准。仔细咂摸一下，这中间很有一些不同寻常的味道。

![](//k.sinaimg.cn/n/sinakd20111/175/w640h335/20251219/65ab-3d6fd8b85655ec546cfb673a95c4880c.png/w700d1q75cms.jpg)

当然，谁都不是吃素的。所以大洋彼岸的科技巨头们通过AAIF强化全球软标准，国内也要加快构建AAIF兼容但可监管的本地标准体系，或者构建自有Agentic AI标准体系了。

摆在大家面前，首先是对这套标准的全面兼容与支持。其实在应用层面，国内厂商始终站在全球市场的前列，在MCP协议推出之后就已快速拥抱，目前都在不同程度的扩展出了MCP应用生态。关于AAIF对全球Agentic AI的影响，这里就不多讲了，可能的话我会再写一篇文章专门分析这个大事件。

这篇文章，王吉伟频道就借盘点全球科技巨头的Agentci AI战略布局与应用进展之际，顺带介绍一下它们的MCP应用生态，希望对大家了解与应用智能体AI有所帮助。注AIGC、IoT、产业升级及数字化转型，专注业务流程、超自动化（RPA）与AI Agent，致力于探索AIGC时代产业升级新机会。

**谷歌：从原型到生产的贯通之道**

谷歌早于行业布局Agentic AI赛道，以模型-框架-平台-生态为核心脉络，构建了覆盖技术研发、开发落地、场景应用全链路的完整体系。模型是Agent智能能力的核心基座，框架是降低开发门槛的工具链，平台是承载部署与运维的关键载体，生态则通过内外部协同拓展场景边界。

这一体系既实现了技术能力的层层递进，又保障了从原型到生产的高效落地，其核心项目布局与协同逻辑，诠释了谷歌对Agentic AI的战略思考。

![](//k.sinaimg.cn/n/sinakd20111/320/w640h480/20251219/9894-08ba6299b7c0da6c9b34b96ee9bf7497.jpg/w700d1q75cms.jpg)

**平台与解决方案**

Agentspace ：一款支持无代码工作流设计、连接 1400 + 数据源打破数据孤岛、提供行业专用预构建agent且具备可视化监控、安全审计与合规管理的企业级智能Agent平台。Vertex AI Agent Framework：企业级全栈托管平台，包括Agent Builder、Agent Engine、Memory Bank和Model Garden四大核心组件，集成运行时、记忆存储、代码执行与监控模块，快速对接企业数据与第三方服务，提供规模化部署与治理能力，降低基础设施投入成本。

## **Project Mariner：浏览器智能Agent，意图驱动浏览，网页智能操作，主动研究助手。**

## **Gemini大模型：Agent能力核心底座，具备工具调用、分步推理、代码执行等原生特性，无缝集成ADK与Vertex平台，兼容LangChain等开源框架，提供强推理驱动。**

Workspace Studio/Agents Marketplace：低代码工具与生态市场，支持模板化创建Agent，非技术用户可快速搭建会议纪要、客服助手等应用，同时实现预验证Agent的分享与复用。

Agent2Agent（A2A）协议：开源互操作标准，支持跨供应商、多框架Agent协同，解决系统孤岛问题，已获50余家科技企业支持。

## **开发者工具链智能Agent：**

## **Gemini CLI：一个命令行 AI Agent，直接在终端中提供智能编程和系统管理能力。**

* **Data Science Agent：Colab 平台集成的 AI 助手，通过自然语言生成完整数据分析 Notebook。**

**开源框架与实现**

Agent Development Kit（ADK）：开源多智能体开发框架，模块化设计，提供多Agent编排、上下文管理、工具插件及评估回放能力，强调工程化可控性，支持Gemini及第三方模型，兼容MCP协议，可本地或混合部署。

Agent2Agent（A2A）协议：基于HTTP、JSON-RPC等规范的开源互操作标准，实现跨供应商、多框架Agent协同，打破系统壁垒。

## **Agent Development Kit (ADK) 智能体开发框架：代码优先开发理念，完整开发生命周期支持，跨模型兼容，多层级智能体架构，开箱即用工具集成。**

Gemini Fullstack LangGraph Quickstart：Gemini 2.5 + LangGraph 框架，构建的深度研究智能体，专为解决复杂问题设计。

Archon：DeepMind 开发的企业级多智能体协作框架，智能体自主构建与优化，多智能体分工协作，领域知识集成。

AlphaEvolve ：DeepMind 研发的革命性编码Agent，算法发现智能体，LLM + 进化算法融合，代码级演化。

Agent Engine，智能体运行与监控平台，与 ADK 配套的生产级基础设施，完整生命周期管理，记忆系统支持，性能优化，灵活部署。

## **落地路径**

以模型-框架-平台-生态为核心脉络，形成全链路技术支撑：

模型层（Gemini）提供核心推理、工具调用等基础能力；

开发层（ADK）提供多Agent编排、工程化开发工具；

部署层（Vertex AI Agent Builder/Agent Engine）负责托管运行、规模化部署与治理；

生态层（A2A协议+Agents Marketplace）保障跨系统协同与Agent复用，实现从原型到生产的高效落地。

**选型建议**

企业内部自动化/流程agent：采用Vertex Agent Builder，结合企业文档、CRM、Ticket系统，构建自动草拟文档、归档票据、触发外部API的Agent；

多-Agent协同工作流：通过ADK构建查询、决策、执行、审计等角色Agent，借助A2A协议实现协作与任务分派，适配复杂决策或研发/运维自动化场景；

低代码/部门自助型Agent：非工程用户使用Workspace Studio及模板，快速生成会议纪要整理、客户支持等轻量化Agent。

**微软：从开源到商用的完整布局**

微软以技术开源赋能+企业级平台支撑+全场景产品落地为核心思路，构建了开源框架-企业平台-产品落地三级Agentic AI体系。

这一体系贯穿研发、部署、治理全流程，既为开发者提供灵活的开源工具链，又为企业打造安全可控的生产级平台，同时通过终端产品实现技术价值的规模化落地，适配从研究验证到商业部署的全场景需求。

Copilot Studio/Agent Builder：低代码可视化工具，快速对接Outlook、Docs等办公数据，支持业务团队自助创建Agent并发布至Copilot/Teams，适合快速原型落地。

GitHub Copilot：集成在 GitHub 和 VS Code 中的 AI 编程Agent，开发者场景标杆，具备代码生成、PR自动提交等Agent能力，是工具链落地典型案例。

Microsoft 365 Agents SDK：专注办公场景部署，提供模板与发布流水线，支持Agent接入Teams、Office等生态。

## **Power Platform智能Agent：**

* Power Pages集成：在网站中嵌入智能体，提供自然语言支持和表单操作Microsoft Learn

**开源框架与SDK**

Microsoft Agent Framework：2025年推出的统一Agent开发框架（Python/.NET支持，MIT协议），整合AutoGen、Semantic Kernel核心能力，提供Agent生命周期管理、编排、工具注册及评估回放功能，是生产级部署的首选迁移目标。

AutoGen：多Agent协作开源框架，以对话式工作流、角色分工为核心，社区活跃，适合研究验证与原型开发，思想已融入统一框架仍持续维护。

Semantic Kernel：轻量级 SDK，擅长技能集合（prompt/插件/规划）复用，适配企业级技能库集成场景。

**Magentic-One：**微软研究院推出的多层级通用多智能体系统，已完全集成到 AutoGen 框架中。

Project Padawan：GitHub Copilot 的配套 Agent，专注于自动化重复开发流程 (环境设置、测试运行、代码合并等)

GitHub Copilot Agent：其 VS Code 扩展已在 2025 年 5 月开源 (MIT 许可证)。

**协同逻辑与落地路径**

层级配合：AutoGen/Semantic Kernel用于研究验证，Microsoft Agent Framework负责工程化迁移，Foundry提供企业级托管治理，Copilot Studio支撑业务快速落地。

落地路径：

* 用AutoGen/Semantic Kernel完成POC验证；
* 迁移至统一框架+Foundry实现生产级部署；3.业务试点优先采用Copilot Studio低代码方案。

**选型建议**

研究验证/原型开发：优先选择AutoGen（多Agent协作）或Semantic Kernel（技能库集成），适配灵活迭代需求；

企业生产级部署：采用Microsoft Agent Framework+Azure AI Foundry，兼顾工程化能力与合规治理需求；

办公场景快速落地：通过Microsoft 365 Agents SDK对接Office生态，或用Copilot Studio低代码构建；

开发者工具链场景：直接复用GitHub Copilot的Agent能力，提升编码效率。

这一体系贯穿开发、部署、运维全链路，适配从初创项目到大型企业的多元需求。

AI Agent Builder/AI Agent Builder能力：低代码可视化工具，快速接入企业数据源，支持自然语言配置Agent边界与策略，加速原型落地。

Frontier Agents：产品化示例（如Kiro、Security Agent），展示长期任务处理与特定领域（开发、安全）落地能力。

第三方生态适配：支持LangChain、AutoGen等主流框架与AWS服务（Lambda、S3等）集成，官方提供部署选型指南。

Policy策略管理：自然语言定义Agent操作边界，Gateway实时校验防越权（如限额退款自动处理）。
