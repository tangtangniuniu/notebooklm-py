# Claude’s code: Anthropic leaks source code for AI software engineering tool

This article is more than 1 month old

Nearly 2,000 internal files were briefly leaked after ‘human error’, raising fresh security questions at the AI company

[Sanya Mansoor](https://www.theguardian.com/profile/sanya-mansoor) and agency

Wed 1 Apr 2026 20.17 BSTLast modified on Wed 1 Apr 2026 20.51 BST

[Share](mailto:?subject=Claude’s code: Anthropic leaks source code for AI software engineering tool&body=https://www.theguardian.com/technology/2026/apr/01/anthropic-claudes-code-leaks-ai?CMP=share_btn_url)

[Prefer the Guardian on Google](https://www.google.com/preferences/source?q=theguardian.com)

Anthropic accidentally released part of the internal source code for its [AI](https://www.theguardian.com/technology/artificialintelligenceai)-powered coding assistant, Claude Code, due to “human error”, the company said on Tuesday.

An internal-use file mistakenly included in a software update pointed to an archive containing nearly 2,000 files and 500,000 lines of code, which were quickly copied to developer platform GitHub. A post on X sharing a link to the leaked code had more than 29m views early on Wednesday, and a rewritten version of the source code quickly became GitHub’s fastest-ever downloaded repository. Anthropic issued [copyright takedown requests](https://www.pcmag.com/news/anthropic-issues-8000-copyright-takedowns-to-scrub-claude-code-leak) to try to contain the code’s spread. Within the code, users spotted blueprints for a Tamagotchi-esque coding assistant and an always-on [AI agent](https://www.theguardian.com/technology/ng-interactive/2026/mar/12/lab-test-mounting-concern-over-rogue-ai-agents-artificial-intelligence), per [the Verge](https://www.theverge.com/ai-artificial-intelligence/904776/anthropic-claude-source-code-leak).

“Earlier today, a Claude Code release included some internal source code. No sensitive customer data or credentials were involved or exposed,” an Anthropic spokesperson said. “This was a release packaging issue caused by human error, not a security breach.”

The exposed code was related to the tool’s internal architecture but did not contain confidential data from Claude, the underlying AI model by Anthropic.

Claude Code’s source code was partially known, as the tool had been reverse-engineered by independent developers. An earlier version of the assistant had its source code exposed in February 2025.

Claude Code has emerged as a key product for Anthropic, as the company’s paid subscriber base continues to grow. TechCrunch [reported](https://techcrunch.com/2026/03/28/anthropics-claude-popularity-with-paying-consumers-is-skyrocketing/) last week that paid subscriptions have more than doubled this year, per an Anthropic spokesperson. Anthropic’s Claude chatbot also received a popularity boost amid the CEO Dario Amodei’s tussle with the Pentagon; Claude climbed to the top spot of Apple’s chart of top free apps in the US just more than a month ago. Amodei had refused to back down on red lines around the use of his company’s technology for mass surveillance and fully autonomous weapons.

This is the second time that Anthropic has had a data leak in recent weeks. Fortune previously [reported](https://fortune.com/2026/03/26/anthropic-says-testing-mythos-powerful-new-ai-model-after-data-leak-reveals-its-existence-step-change-in-capabilities/) on a separate breach and noted that the company was storing thousands of internal files on publicly accessible systems. That included a draft of a blog post that referred to an upcoming model known as “Mythos” and “Capybara”.

Some experts worry the leaks suggest internal security vulnerabilities within Anthropic. That could be particularly troubling for a company focused on AI safety.

The leaks could also help competitors, like OpenAI and Google, better understand how Claude Code’s AI system works. The Wall Street Journal [reported](https://www.wsj.com/tech/ai/anthropic-races-to-contain-leak-of-code-behind-claude-ai-agent-4bc5acc7?gaa_at=eafs&gaa_n=AWEtsqd52OPYWKSd0WfODTfedHW-sm2oXe_rY5IjJd8rO2j1T1_Y_esjPdD4JYU79GI%3D&gaa_ts=69cd6367&gaa_sig=FX2D1D1m1xMdTq_GOKCSTYidiAgWr4uCVNXtftGD_ZVHA9oKUiyd-wffyPbxtDREhko0DumYNcVqEyPVQf6bCg%3D%3D) that the most recent leak included commercially sensitive information, such as tools and instructions for getting its AI models to work as coding agents.

The latest breach comes weeks after the US government designated Anthropic as a [supply chain risk](https://www.theguardian.com/technology/2026/mar/09/anthropic-artificial-intelligence-pentagon); Anthropic is fighting those allegations in court. Last week, a US district judge granted a temporary injunction to block the designation.
